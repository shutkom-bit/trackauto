# Сайт TrackAuto — статична версія

Звичайний сайт без збирання: HTML + CSS + JS. Працює на будь-якому хостингу.

## Структура
- `index.html` — уся сторінка (тексти, розділи, посилання)
- `assets/styles.css` — стилі. Кольори й шрифти — на початку файлу, у `:root`
- `assets/main.js` — меню на мобільному, підбір обладнання (масив `TASKS`), форма заявки
- `assets/favicon.svg` — іконка вкладки

## Як переглянути
Відкрийте `index.html` у браузері (подвійний клік).

## Як розмістити
- **Звичайний хостинг (cPanel, Ukraine.com.ua, Hostinger тощо):** завантажте вміст папки в `public_html` через файловий менеджер або FTP.
- **Netlify / Cloudflare Pages / Vercel:** перетягніть папку в панель — сайт отримає адресу за хвилину, потім підключіть домен trackauto.com.ua.
- **GitHub Pages:** створіть репозиторій, завантажте файли, увімкніть Pages у налаштуваннях.

## Форма заявки
Зараз форма відкриває лист на office@trackauto.ua з заповненими полями.
Щоб заявки приходили напряму:
1. Створіть форму на https://formspree.io (або використайте Netlify Forms чи власний бекенд).
2. Вставте її адресу в `index.html`: `<form ... data-endpoint="https://formspree.io/f/XXXX">`.

## Що ще замінити
- Екран у першому блоці — на реальний скриншот Navixy (зараз це SVG-ілюстрація).
- Кейси (`[KPI]`, `[Назва клієнта]`) — на реальні.
- Посилання картки «Мені потрібен застосунок» — на App Store / Google Play.
- Кнопка EN — коли з'явиться англійська версія.
